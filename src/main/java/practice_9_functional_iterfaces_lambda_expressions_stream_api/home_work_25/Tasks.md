# Java Homework: Functional Interfaces, Lambda Expressions, and Stream API

## Part 1: Functional Interfaces and Lambda Expressions

### Task 1: Create a Custom Functional Interface

Write an interface called `MathOperation` that takes two numbers and returns the result of an operation.

Implement it using lambda expressions for the following operations:
- Addition
- Subtraction
- Multiplication
- Division

### Task 2: Using an Anonymous Class

Create an anonymous class that implements the `Runnable` interface and prints the message `"Hello from anonymous class!"`.

### Task 3: Lambda Expression with Predicate

Write a lambda expression that checks whether a number is even.

### Task 4: Lambda Expression with Function

Create a lambda expression that takes a string and returns its length.

### Task 5: Using Consumer

Write a lambda expression that takes a string and prints it to the console.

## Part 2: Stream API – Basic Operations

### Task 1: Filter Strings with a Length Greater Than 5

Write a program that takes a list of strings and removes all strings with a length of 5 characters or less using the Stream API.

### Task 2: Filter Numbers Divisible by 5

Write a program that takes a list of numbers and selects only those that are divisible by 5 without a remainder using the Stream API.

### Task 3: Convert Strings to Their Lengths

Write a program that takes a list of strings and replaces each string with its length using the Stream API.

### Task 4: Create a List of Squared Numbers

Write a program that takes a list of numbers and transforms it into a new list where each number is replaced by its square using the Stream API.

### Task 5: Remove Duplicates from a List

Write a program that takes a list of elements and removes all duplicates using the Stream API.

## Part 3: Stream API – Aggregate Operations

### Task 1: Find the Maximum Element

### Task 2: Find the Minimum Element

Write a program that takes a list of numbers and finds the smallest number using the Stream API.

### Task 3: Calculate the Sum of All Elements

Write a program that takes a list of numbers and calculates their sum using the Stream API.

### Task 4: Find the First Element Starting with "Б"

Write a program that takes a list of strings and finds the first string starting with the letter "Б" using the Stream API.

### Task 5: Check if Any Element Matches a Condition

Write a program that checks whether at least one element in a list satisfies a given condition (for example, whether it is an even number) using the Stream API.
