# Homework23 Tasks:

## 1. Exception Handling Tasks

### Task 1: Handling a Checked Exception

Write a program that attempts to open a file named `data.txt`.
If the file is not found, the program should handle the exception and print the message: `File not found`.

### Task 2: Handling an Unchecked Exception

Write a method that takes two numbers as input and performs division.
Handle the situation when the second number is zero to avoid a division-related exception.

### Task 3: Creating and Using a Custom Checked Exception

Create a method that validates a user's age.
If the age is less than 0 or greater than 150, the method should throw a custom checked exception.

### Task 4: Creating and Using a Custom Unchecked Exception

Write a method that takes a string as an argument and checks whether it is a valid email address.
If the string does not meet the required criteria, the method should throw a custom unchecked exception.

## 2. Generics Tasks

### Task 1: Generic Class

Create a generic class called `Box` that can store an object of any type.
The class should have methods to set and get the value stored inside the box.

### Task 2: Generic Method

Write a generic method called `printArray` that accepts an array of any type and prints each element to the console.

### Task 3: Generic Class with Two Type Parameters

Create a generic class called `Pair` that can store two objects of different types.
The class should allow you to get and set each object.
